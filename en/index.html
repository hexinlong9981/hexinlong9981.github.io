EchoLab — an AI assistant that never lets the AI do the math

Oct 2026 – present · personal project

Code: github.com/hexinlong9981/echolab (MIT) · Docs: user guide (EN / JA / ZH) · Demo: web UI

An unofficial fan project built around character building in the game Wuthering Waves. It answers questions where one wrong number destroys trust: damage comparisons, scoring, gacha probabilities. Because LLMs tend to invent plausible numbers, it is designed so that every number in an answer comes from a calculation service and can be traced to its source.

  • Java 21
  • Spring Boot
  • Spring AI (MCP)
  • Python
  • React
  • TypeScript
  • Claude / Gemini API
  • Docker
  • GitHub Actions
  • Cloud Run
  • Cloudflare Workers
  • Numbers only from tools: the LLM writes an answer template with placeholders, and a renderer fills in values by source ID. Any number without a source sends the answer back for a rewrite. Differences and ratios are also computed by tools.
  • Java calculation service: built calc-engine with Java 21, Spring Boot and Spring AI. As an MCP server it provides expected damage, scoring and gacha probabilities (exact and Monte Carlo).
  • Safe tool calls: a deny-by-default gateway exposes only declared tools and validates inputs with JSON Schema; external strings are treated as data, not instructions. Screenshot OCR reads only the numeric fields a template declares, and a prompt-injection eval set runs in CI on every change.
  • Extensible structure: a domain-independent core is separated from "domain packs". Two packs added later, a mortgage calculator and a spoiler-safe lore guide for Mushoku Tensei, required no changes to the core, and CI checks this.
  • Testing and quality: the same golden cases are checked in three places: Java, a Python reference implementation and end-to-end tests over MCP. JUnit, jqwik (property tests), ArchUnit, Error Prone, JaCoCo (90%+ line coverage), pytest and ruff run on GitHub Actions.
  • Cost control: the cost of every LLM call is computed from a price table and logged, with caps of USD 1 per day and USD 10 per month; past the cap, the LLM is not called.
  • Web UI and deployment: trace replay and an evaluation dashboard in React + TypeScript + Vite, served as static files on Cloudflare Workers; a demo server runs on the Google Cloud Run free tier. The UI and docs are available in Japanese, English and Chinese.
  • Documentation: 14 ADRs and an architecture document record the reasons and trade-offs behind each choice. I use AI coding tools such as Claude Code and verify the results through tests and code review.
