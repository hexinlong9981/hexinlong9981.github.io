项目经历

EchoLab —— 不让 AI 做计算的 AI 助手

2026.10 – 至今 · 个人项目

代码：github.com/hexinlong9981/echolab（MIT）· 说明：使用说明（中・日・英） · 演示：网页界面

以游戏《鸣潮》的角色培养为题材（非官方粉丝作品），回答伤害比较、评分、抽卡概率等“错一个数字就失去信任”的问题。 LLM 容易编造看似合理的数值，本项目从设计上保证回答中的每个数值都来自计算服务，并能查到出处。

  • Java 21
  • Spring Boot
  • Spring AI（MCP）
  • Python
  • React
  • TypeScript
  • Claude / Gemini API
  • Docker
  • GitHub Actions
  • Cloud Run
  • Cloudflare Workers
  • 数值只来自工具：LLM 只写带占位符的回答模板，数值由渲染器按出处 ID 填入；回答中若出现没有出处的数字就退回重写。差值、比值也由比较工具计算。
  • Java 计算服务：用 Java 21 + Spring Boot + Spring AI 实现 calc-engine，作为 MCP 服务器提供期望伤害、评分、抽卡概率（精确解与蒙特卡洛法）等计算。
  • 安全的工具调用：网关只放行配置中声明的工具（默认拒绝），用 JSON Schema 校验输入；外部字符串当作数据而不是指令。截图 OCR 只读取模板声明的数值字段，并用提示词注入评估集在 CI 中每次检查。
  • 可扩展的结构：把领域无关的核心与“领域包”分离。之后加入的房贷计算、《无职转生》设定考证（按用户进度防剧透）两个领域包都没有修改核心代码，CI 自动检查这一点。
  • 测试与质量：同一组黄金用例在 Java、Python 参考实现、经由 MCP 的端到端测试三处核对。使用 JUnit、jqwik（性质测试）、ArchUnit、Error Prone、JaCoCo（行覆盖率 90% 以上）、pytest、ruff，在 GitHub Actions 中运行。
  • 成本控制：按价格表计算每次 LLM 调用的费用并记账，设置每日 1 美元、每月 10 美元的上限，超过后不再调用。
  • 网页界面与发布：用 React + TypeScript + Vite 做执行轨迹回放与评估看板，以静态文件发布到 Cloudflare Workers；演示服务器部署在 Google Cloud Run 的免费额度内。界面与文档均支持中・日・英三种语言。
  • 文档：写了 14 篇设计决策记录（ADR）和架构说明，记录每个选择的理由与取舍。开发中使用 Claude Code 等 AI 编程工具，并通过测试与代码审查确认结果。
